# 减少 SLM 层数与输出方式实验：Dev 与 Test 结果汇总

## 1. 评估范围与统计方式

- Dev 数据：IntPhys public Dev。主对比表对 O1/O2/O3 做宏平均；Excel 补充的历史 MLP 实验只有 O1 记录，因此单独列出。
- Test 数据：用户回填的官方评分结果及实验汇总工作簿记录；主表仅统计 O1 maximum，不使用自动填充的 O2/O3。
- `avg/max` 分别对应窗口损失的平均聚合和最大聚合。
- 所有实验相同的参数（例如无记忆、batch size 等）不在参数表中重复列出。
